# 业务规则：新需求覆盖（S3）

1. 产品数 < 2 → 不能算（请改用单产品函数/S2）
2. 数量未定 → 只输出产品 BOM 共用清单（全部传入产品的子件交集）；禁止满足结论
3. 有数量：
   - 每单净需求 = `max(0, X×单耗 − 可用 − 在途PO)`
   - 争用：共享池 = 可用 + 在途，按需求顺序扣减
   - 产品级对照：`total_sellable_qty >= demand_qty` → 已满足（对照，不是物料级结论）
4. 替代组内覆盖用 **MAX**（与 S2 一致）；未确认替代 → 不能算
5. 在途只计未关闭 PO；PR 不进供给
6. 不要把结构共用清单的 `shared_count` 当成争用缺口
