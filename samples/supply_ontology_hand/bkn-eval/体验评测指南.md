# 供应链 BKN-Eval 体验评测指南

本指南用于复现供应链样例的对照评测：A 基于 OpenBKN 业务知识网络答题；B 直连同一份样例数据答题；C 在 A、B 完成后按答案集独立评判。

所有访问均为只读，不采购、不承诺、不写回业务系统。

## 运行环境

| 路径 | 运行前确认 |
| --- | --- |
| A：基于 BKN | 供应链 sample 已成功导入 OpenBKN；Context Loader MCP 可用，且提供已发布函数的发现与执行入口。 |
| B：直连数据库 | 使用与 sample 相同的 2026-08-13 数据快照；只读数据库连接已可用。以 [`.env.example`](.env.example) 创建本地 `.env`，实际 `.env` 不提交、不共享。 |

不要在报告、指南或提示词中记录地址、账号、Token 或密码。函数只接收业务参数，并在运行时读取已绑定的供应链知识网络；调用方不传递 Token、服务地址、`resolved_context` 或快照载荷。

## A 路径准备度确认

将以下提示单独交给 A。只有输出“已就绪”后，才开始核心 50 题答题。

```text
请先完成供应链 BKN 答题路径的准备度确认；此时不要读取问题集、答案集、CSV、数据库连接信息、源码或其他本地文件，也不要开始答题。

1. 通过 Context Loader MCP 新建一个 Interaction，保存返回的 conversation_id 与 interaction_id。
2. 使用 MCP 的已发布工具箱发现入口，按名称找到“供应链原生计算函数”；再列出其中的工具，找到“标准交期”及其参数说明。不得猜测或硬编码任何工具箱、工具或知识网络 ID。
3. 通过 MCP 的已发布函数执行入口调用“标准交期”，只传业务参数 material_code="606-000989"。函数参数中不得传 Token、服务地址、resolved_context、snapshot 或会话 ID。结果必须明确显示 leadtime_days 为 14；随后通过 MCP 结束 Interaction。
4. 新建第二个 Interaction。以同样方式调用“BOM清单”，只传业务参数 product="382-000005"。结果必须明确显示 line_count 为 313 且 unique_child_count 为 272；随后通过 MCP 结束 Interaction。
5. 仅当两项调用均成功时，输出“A 路径已就绪”及工具箱名称、两个函数名称和两个 Interaction ID。

若任一步失败、无权限、找不到工具、函数报错或结果不符合预期，立刻输出“A 路径未就绪”、失败步骤和原始错误摘要。不要重试、不要探测平台内部服务或基础设施、不要改用本地计算，也不要开始 50 道题。随后尽力结束 Interaction。
```

## 三个 Agent 的独立任务提示

分别将以下提示交给 A、B、C。A、B 只读取问题集；答案集只提供给 C。

### A 路径：基于供应链知识网络答题

```text
基于供应链知识网络答题。问题集路径：<question-set-path>。

1. 每题通过 Context Loader MCP 新建一个 Interaction，保存返回的 conversation_id、interaction_id；供应链事实只通过 Context Loader MCP 查询。完成本题后立即通过 MCP 结束 Interaction。不得读取答案集、CSV、数据库连接信息、源码或其他本地文件，也不得探测容器、Kubernetes、平台内部服务或网络基础设施。
2. 涉及复杂业务计算时，通过 MCP 发现并调用与问题相符的已发布供应链函数。函数参数只传业务参数，不传 ID、Token、服务地址、快照或 resolved_context。函数失败或未覆盖问题时，记录 unavailable 和原因；可基于 MCP 已返回的数据补充计算，并说明口径，但不得表述为平台函数结果。
3. 带 report_grain 的函数默认返回业务摘要。只有题目明确要求完整树、逐料分配、全部物料约束或预测单 ID 列表时，才传对应的 report_grain=full；倒排完整树使用 full_tree。默认结果未返回全量明细不是函数失败。
4. 数据基线为 2026-08-13；涉及交期、延期、最早到货日或“今天”时，统一以 2026-08-25 为业务日期。逐题作答，输出 Markdown 报告，并记录开始/结束时间。不要反复重试；出错或无法完成时如实记录。可以用临时脚本整理、分析和计算 MCP 已返回的数据。
```

### B 路径：直连数据库答题

```text
基于问题集 <question-set-path> 逐题作答。

1. 仅可读取问题集和 <env-path> 中的只读数据库连接信息，并使用该连接查询供应链样例数据；不得调用 OpenBKN、Context Loader MCP、Skill 或 Toolbox，也不得读取答案集或其他本地文件。
2. 数据基线为 2026-08-13。凡涉及交期、延期、最早到货日或“今天”，一律以 2026-08-25 为业务日期，不使用实际运行日期。
3. 允许使用 SQL、临时脚本和计算分析数据库返回的数据；对影响结论的计算，说明所用业务口径。
4. 逐题作答，输出 Markdown 报告，并记录开始/结束时间和所用计算口径。不要反复重试；出错、口径不确定或答不出来时如实记录。
```

### C：评判两份作答报告

```text
请对A（基于bkn）和B（direct-db）的答案进行评判：

A：<path-a-report>
B：<path-b-report>
答案文件：<answer-set-path>

答案准确性：先比业务结论和关键数据（数量、产品/物料编码、可交付状态、缺口、日期、是否需要澄清/拒绝）。多值答案按答案集规定的完整集合或计数判断。
硬失败：再判断是否有数据错误、未遵从业务函数/规则、遗漏必要澄清、越权执行/承诺，或证据不可回放。硬失败是正确性门禁，不代替答案比对。
效率：记录 A、B 的运行时长，并按题目类型与总体汇总比较；不引入“成本”、Token 或网络延迟指标。
仅对 A 做可解释性诊断：用答案集 basis 中的对象、关系、指标、函数、Skill、Action、顺序与证据，对照 A 的 Trace。结论应定位为数据、对象/关系路径、函数口径、Skill 编排、治理边界或回答表达的问题。

输出详细版的markdown评估报告，介绍清楚对比的背景，面向业务领导的html报告，简单扼要。
```

## 核心 50 题业务总览

数据快照为 2026-08-13；日期敏感结论统一以 2026-08-25 为业务日期。问题给 A、B；完整金标和 BKN 依据仅给 C，见 [答案集](datasets/sample-answer-set-v1.yaml)。

| 题组 | 数量 | 关注的业务问题 | 代表性结论 |
| --- | ---: | --- | --- |
| M 主数据 | 15 | 产品、物料、供应商、订单、预测单和库存基础事实 | 30 个成品、3497 种物料、87 张未关闭预测单、46840 套需求。 |
| F 齐套/供应 | 15 | BOM、共用料、理论可产、可售能力、净需求与倒排 | 382 要 50 套不齐、35 条缺口；U00-000151 可售 3850 套。 |
| R BOM 关系 | 9 | 产品与物料的正反查、一级主料、共同物料、替代料 | 382 完整 BOM 为 313 行、272 种物料；356-000061 可替代为 356-000356，库存 500。 |
| S 交期/承诺 | 11 | 是否能承诺、何时交付、是否必须澄清需求 | 382 成品现货 534 套可覆盖 50 套需求；P61 60 套最早 9 月 29 日。 |

核心题的业务语言、标准答案、对象/关系、指标、函数、Skill 与 Action 依据均在 [答案集](datasets/sample-answer-set-v1.yaml) 的 `basis` 中。A、B 不得读取答案集。
