3. 关键差异（白话）

  1. BOM 共同物料种数（F-02 / F-03 / F-12 / S-05）
    标准：28 / 11 / 18 / 28。BKN 一致；直连库报 38 / 17 / 26 / 38——自定「全层级主料」口径与标准不一致。
  2. 可售与理论可产（F-04 / F-05 / F-08 / F-09 / F-13 / S-02）
    标准示例：382 可售 534（理论可产 0）；U00-000151 可售 3850（理论 50）。BKN 一致；直连库偏高（如 568 / 3920，理论 34 / 120）。
  3. 齐套缺料明细（F-06 / F-10 / F-11 / S-03 / S-04）
    结论「不齐套 / 不能一起承接」两边常一致，但标准要求的缺口条数与料号：BKN 对齐（如 35 条、321-000569）；直连库多为「叶子缺口 1 种」且料号不同。
  4. 齐套倒排节点数（F-14）与交付承诺细节（S-01）
    标准：57 个节点；不能按期、延迟 176 天等。BKN 答出；直连库因找不到预测单号 0000023181 答不出 / 只能近似。
  5. 替代料未确认能否给数（F-15）
    标准：确认前不能给可售数。直连库正确拒绝；BKN 声明应确认后，仍给出了假设口径下的 534。

5. 给领导的阅读提示

  • 查数、点库存：两种路径都能用，差异不大。
  • 算可售、齐套、倒排：需要统一业务口径；BKN 路径因绑定了标准函数/技能，更贴近本次冻结答案。
  • 合规红线：两边都不会擅自下采购单或空口承诺交期；直连库在「替代料未确认不给数」上更严。
  • 局限：直连库自写算法与仓库集合是临时约定；BKN 侧本次 Toolbox 线上不可用，复杂题用了配套离线函数 + 线上核对。
