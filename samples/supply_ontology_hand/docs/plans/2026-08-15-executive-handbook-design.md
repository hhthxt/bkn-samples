# 供应链 Sample 业务案例白皮书设计

## 目标

将现有简要 `docs/handbook.html` 扩展为面向业务部门负责人、客户和生态伙伴的中文案例白皮书。读者无需先理解 OpenBKN 技术细节，即可理解业务问题、数据基础、知识网络能力、体验方式和验证结论。

## 读者与边界

- **业务领导**：看到业务价值、场景覆盖、风险与放行边界。
- **客户/伙伴实施者**：看到数据准备、两种体验路径和可复现实测入口。
- **技术评审者**：可追溯对象、关系、指标、函数、Skill、Action 与原始报告。
- 不将 localhost Benchmark 误写为 POC Agent 全闭环；不暴露数据库密码、Catalog ID、Token 或其他环境专用凭据。

## 信息架构

1. 封面与执行摘要：Sample 定位、核心数值、发布范围。
2. 业务需求与故事：预测需求到交付判断、S1/S2/S3 和人工确认的流程图。
3. 场景地图：基础问答、供应承诺、Skill 发现、受控 Action 的输入、输出与治理点。
4. 数据基础：12 表、78,635 行、产品/物料/BOM/库存/预测等数据说明与关键金标。
5. 业务知识网络：15 对象类、19 关系、8 指标、函数、3 Skill、3 Action 的业务化矩阵。
6. 交付与体验：人工路径与 Agent 路径、第三方需要自备的环境条件。
7. 验证仪表板：localhost Benchmark、第三方 Playbook、POC 实测分别标注证据和范围。
8. 发布边界与下一步：已放行项、未放行项、Foundry 能力依赖。
9. 参考入口：README、操作手册、测试集、Benchmark、POC 报告的相对链接。

## 呈现方式

静态、零外部依赖的单页 HTML。使用内嵌 CSS、可打印版式、卡片、表格和 Mermaid 风格的纯 CSS 流程图；不使用 CDN 或需要联网的脚本。HTML 保持中文，适配桌面阅读和导出 PDF。

## 验证

- HTML 文件存在、`lang="zh-CN"`、包含九个核心章节和所有相对报告链接。
- `tools/verify_sample.py` 全量通过。
- 本地使用浏览器/渲染工具检查标题、表格与流程图可读。
