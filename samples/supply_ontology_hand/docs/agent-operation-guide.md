# Agent 操作手册

## 适用范围

本手册用于数据库表已由环境操作者导入、Catalog 已扫描、供应链知识网络已导入并完成对象绑定之后。数据库密码和 Catalog 配置由人工处理，Agent 不应索取、保存或读取这些信息。

## Agent 的标准路径

1. 通过 OpenBKN MCP 列出知识网络，确认供应链知识网络可用。
2. 为本轮业务问题创建受管 Interaction，并在结束时正常关闭。
3. 使用 Context Loader MCP 查询产品、预测、库存、BOM 或指标等业务事实。
4. 调用 MCP 的 list_published_toolboxes 和 list_published_tools，按业务名称发现供应链原生计算函数。
5. 调用 execute_published_tool；只传该函数 schema 要求的业务参数。
6. 输出业务结论、依据、适用口径和无法完成的原因。

函数会在 OpenBKN 的受控运行时读取已绑定知识网络。Agent 不传递 Token、服务地址、数据快照、resolved_context 或函数内部会话参数；也不使用 CSV 或本地计算替代线上函数结论。

## 场景选择

- 查询当前现货和可售能力：合计可售。
- 判断一个产品要 X 套是否齐套：要 X 套净需求与齐套。
- 判断多个产品需求能否同时承接：共用料与多需求争用。
- 判断某个截止日能否履约：生产计划齐套倒排。
- 判断一个物料会影响哪些产品：物料反查产品。

S1、S2、S3 Skill 用于识别完整业务场景和生成解释；简单事实问题不必先调用 Skill。所有写入型 Action 只可在人工确认后执行；当前样例的 Action 仅作 dry-run 演示。
