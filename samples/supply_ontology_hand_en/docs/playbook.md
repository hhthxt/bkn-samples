# Fulfillment Commitment Playbook

## User goal

Determine whether a product quantity can be delivered by a deadline and explain the binding constraints.

## Agent flow

`identify forecast → retrieve supply evidence → calculate deliverable quantity → explain substitution policy → return conclusion → confirm before Action`

## Pass criteria

- Do not treat a historical forecast as a future commitment.
- Respect the no-substitution constraint.
- Link the conclusion to inventory, BOM, production capacity, or purchasing evidence.
- Actions must start as dry-runs and require confirmation before execution.
